# 데이터 구조 (B 트랙, v0.1)

스키마 파일: `06_코드/schemas/` · 설정: `06_코드/experiment_config.json`
형식 예시(값은 모두 가상): `06_코드/schemas/examples/`

## 폴더 구조

| 폴더 | 내용 | 파일 규칙 |
|---|---|---|
| `01_리서치_원본/` | 입수한 PDF 원본 | `YYYY-MM-DD/` 아래에 다올·유진 PDF |
| `02_시장데이터/스냅샷/B/` | T 시각 시장 데이터 + 미국 종가 + 리포트 입수 시각 | `YYYY-MM-DD.json` (snapshot 스키마) |
| `02_시장데이터/정답/B/` | 장 마감값 | `YYYY-MM-DD.json` (answer 스키마) |
| `03_가공데이터/B/YYYY-MM-DD/` | 예측 세션이 보는 **입력 패키지** (스냅샷 + PDF 사본 + 해시 목록) | 정답은 넣지 않음 |
| `04_예측결과/B/` | AI 예측 | `YYYY-MM-DD.json` (prediction 스키마), 저장 후 수정 금지 |
| `05_평가결과/B/` | 일별 평가, 누적 성과, LLM 근거 평가 | 평가 단계에서 설계 |
| `06_코드/` | 스키마, 설정, 이후 실행·평가 코드 | |
| `99_로그/` | 입수 시각 로그, 실행 로그, `late`/`missing` 기록 | |

A 트랙을 추가하면 같은 위치에 `A/` 하위 폴더를 만든다.

## 하루 흐름

```text
~10:00  PDF 2종 입수 → 01_리서치_원본/날짜/ (생성·입수 시각 기록)
10:00   스냅샷 기록 → 02_시장데이터/스냅샷/B/날짜.json
10:00   입력 패키지 생성 → 03_가공데이터/B/날짜/
        예측 세션 실행 → 04_예측결과/B/날짜.json
장 마감 후  정답 기록 → 02_시장데이터/정답/B/날짜.json
        평가 → 05_평가결과/B/
```

## 필드 규칙

- **방향(direction)은 선물 가격 기준.** 상승 = 금리 하락 = Long Duration. `duration_view`는 up→long, down→short, neutral→neutral과 일치해야 한다.
- **파생값은 저장하지 않고 평가 단계에서 계산:** 잔여장 변화 = `정답 close` − `value_at_t`. 틱 = 변화 ÷ `tick_size`.
- **시각은 모두 KST(+09:00)**, 초 단위까지 기록.
- 스냅샷에는 값을 **기록한 시각(captured_at)** 과 **리포트 입수 시각(obtained_at)** 을 모두 넣어, `late` 판정과 누수 검증의 근거로 쓴다.
- `input_manifest_sha256`: 입력 패키지의 파일 목록과 해시로 계산한 값. 사후에 입력이 바뀌지 않았음을 증명한다.

## 구현 시 검증할 규칙 (스키마로 표현 불가)

1. 확률 합계 = 1 (허용 오차 0.01)
2. `direction`이 `prob`의 최댓값과 일치
3. `duration_view`가 `direction`과 일치
4. `captured_at` ≤ `scheduled_at` + `late_tolerance_minutes` → 초과 시 `late`
5. `pdf_created_at`·`obtained_at`이 `scheduled_at` 이후면 해당 리포트는 입력에서 제외하고 기록. `obtained_at`은 PDF 하단 FnGuide 워터마크의 다운로드 시각을 사용 (`04_PDF읽기_검증.md`)
8. 가격·전일 종가는 스냅샷을 정본으로 사용. 두 리포트의 1주 변화·국고채 수익률은 서로 다르므로 프롬프트에서 출처를 명시하게 함
6. `executed_at` ≥ `captured_at`, 정답 `recorded_at` > 예측 `executed_at`
7. 같은 날짜의 예측 파일이 이미 있으면 덮어쓰기 거부

## 미확정 (설정 파일의 `pending`)

- 틱 크기 검증: 현재 10년·3년 모두 0.01로 가정 (미검증)
- 중립 구간 N틱: 미정 (null)
- 종가 정의: 시각·출처 미고정

## 격리 실행 (구현 단계 과제)

예측 세션은 `03_가공데이터/B/날짜/` 안의 파일만 접근해야 한다. 정답 폴더는 같은 프로젝트 안에 있으므로, 실행 시 입력 패키지를 프로젝트 밖 임시 폴더로 복사해 그곳에서 실행하는 방식을 우선 검토한다.
