# 통합 기획안 v0.3 — 데일리 리서치 + 전일 종가 기반 다음 거래일 예측 (멘토 안)

> 상태: 초안 (2026-11-09). 멘토의 원래 기획을 주 트랙으로 채택하고, v0.2의 누수 방지·평가 구조를 그대로 가져옴.
> v0.2의 B 트랙(10:00 → 당일 마감)은 **중단·보관**. 코드는 남겨 두고 운영하지 않는다.
> `[결정필요]`는 사용자 확정 전까지 잠정값.

---

## 0. 멘토 기획 (원문 요지)

1. FnGuide에서 매일 쓸 데일리 리서치를 하나 정한다.
2. 함께 줄 정보를 정한다. 예: 전일 미국 지수·채권·환율, 국내 지수·채권·환율 종가.
3. AI가 데일리와 전일 정보를 바탕으로 **다음날**을 근거와 함께 예측한다.
4. 이를 **LLM으로 평가**한다.

## 1. 핵심 질문

> 데일리 리서치 1개와 전일 종가만으로, AI가 다음 거래일 국내 채권 방향을 **단순 기준선보다 낫게** 맞히는가? 그 근거는 타당한가?

거래 없이 예측과 평가만 기록한다.

## 2. 하루 흐름 (거래일 D)

```text
D-1 15:45   국내 장 마감 (국채선물)
D   새벽    미국 장 마감
D   08:30   [기록] D-1 종가 입력 + 데일리 리포트 확보
            [예측] 격리된 AI 세션이 D 종가 방향·근거 예측 → 저장 후 수정 불가
D   08:45   국채선물 개장 (= 예측 컷오프)
D   15:45   [정답] D 종가 기록 (별도 폴더)
D   마감 후  [평가] LLM 근거 채점 + 수치 기록
```

- **컷오프 08:45.** 이후 실행분은 `late`로 분리하고 정식 성과에서 제외한다.
- 개장 전에 실행하므로 간밤 미국 장 결과가 반영된다(v0.2 A 트랙의 약점 해소).

## 3. 입력

### 데일리 리서치 (확정, 2026-11-09)
- FnGuide의 **DAOL Daily Bond Morning Brief + Eugene's FICC Update** (기존 선정 유지, 08:45 전 발간).
- 입수 시각 = PDF 워터마크의 다운로드 시각. **08:45 전에 내려받은 D일자 발간본만** 그날 입력으로 쓴다. 못 받은 날은 `late`.
- 11/05 샘플은 09:57·10:08에 내려받았으므로, 첫 5거래일의 게시·입수 시각을 기록해 점검한다.

### 전일 종가 (스냅샷 정본)

| 구분 | 항목 | 입력 방식 |
|---|---|---|
| 국내 D-1 | 3Y·10Y 국채선물, KOSPI200, 원/달러 | 직전 정답 파일에서 자동 |
| 미국 D-1 | S&P500·Nasdaq 등락률, 미국채 10Y 1일 변화(bp) | 아침에 수동 3개 |
| 참고 | 국고채 금리, 미국채 2Y, DXY, 유가 등 | 리포트 수치 사용 |

- 미국 값은 D-1 미국 장(한국 시각 D 새벽 마감) 기준.
- 국채선물은 **같은 월물끼리** 비교한다. 만기 교체 주간에는 어느 월물을 쓸지 미리 정해 둔다 `[결정필요]`.
- 상세: `02_예측시점_및_타깃.md`, `03_데이터구조.md` (트랙명 **A**).

## 4. 예측 대상과 출력

- **주 타깃:** 10년 국채선물, **D 종가 − D-1 종가 (틱, 1틱 = 0.01pt)**
- 보조: 3년 국채선물, KOSPI200, 원/달러
- 출력 JSON: 방향(up/neutral/down), 확률, 예상 틱, 확신도(상/중/하), 근거(상승 요인·하락 요인·이미 반영된 요인·무효화 조건). v0.2 스키마의 구조를 그대로 쓴다.
- **중립 구간:** 일간 변동은 장중보다 커서 B 트랙의 3틱을 그대로 쓰지 않는다. 일별 종가는 쉽게 구할 수 있으므로 **과거 1년 일간 변동 분포로 산정**한다 `[결정필요]`.

## 5. 평가

**LLM 평가 (멘토 요청, 중심):** 장 마감 후 예측과 **별개의 세션**이 정답을 보고 채점한다.
- 근거 수치가 리포트·입력 값과 맞는지 (원문 행·열까지 대조)
- "이미 반영" 판단과 무효화 조건이 타당했는지
- 맞았어도 근거가 부실하면 낮게, 틀렸어도 합리적이었으면 높게 (결과론 금지)
- 다음 예측에 쓸 일반화 가능한 교훈

채점 모델은 예측 모델과 다른(상위) 모델을 써서 자기 선호 편향을 줄인다.

**수치 기록 (함께 남김):** LLM 평가가 후하거나 결과에 끼워 맞추는지 대조하기 위한 용도.
- 주 지표(사전 고정): 비중립 예측의 방향 적중률, 신호당 평균 획득 틱

**기준선:**
1. 전일 국내 움직임 지속
2. 전일 국내 움직임 반전
3. 항상 중립
4. 데일리 리포트의 방향 전망 추종
5. **간밤 미국채 10Y 금리 방향 추종** (미국 금리 하락 → 국채선물 상승). 이길 만한 가장 강한 단순 규칙일 가능성이 큼
6. AI 예측

## 6. 누수 방지

- [ ] 리포트 입수(워터마크) 시각 ≤ 08:45 (아니면 그날은 `late`)
- [ ] 예측은 08:45 전 실행, 저장 후 수정 불가
- [ ] 정답은 별도 폴더, 예측 세션 접근 불가
- [ ] 매일 새 격리 세션 (전역 설정·메모리 미로드)
- [ ] 프롬프트 버전·모델 ID 기록
- [ ] 과거 날짜 소급 검증 시 모델 지식 컷오프 이후 날짜만 사용

## 7. 실험 버전

- **V0 (시험 운영, ~20거래일):** 파이프라인 검증. 성능 결론 없음.
- **V1:** 프롬프트 고정 운영. 성능 판정에는 약 150거래일 필요. 일별 종가와 과거 리포트를 구할 수 있으면 **소급 검증으로 단축** 가능(분봉이 필요했던 B 트랙보다 훨씬 쉬움).
- **V2:** 입력 요인을 하나씩 추가하며 V1과 비교.

## 8. 기존 구현 재사용

| 구성 | 처리 |
|---|---|
| 격리 실행 (`run_prediction.py`) | 그대로. 입력 파일 구성만 변경 |
| 기록 (`record.py`) | 입력 항목을 전일 종가 목록으로 변경 |
| 예측 스키마·지침 | 타깃을 "다음 거래일 종가"로 수정 → 지침 v2.0 |
| 수치 평가 (`evaluate.py`) | 정답 기준을 전일 종가 대비로, 기준선 5번 추가 |
| 근거 채점 (`judge_rationale.py`) | 그대로. 지침 문구만 수정 |
| B 트랙 데이터·결과 | 보관 (운영 중단) |

## 9. 진행 순서

1. ✅ 데일리 리서치: 다올·유진 유지 (5거래일 입수 시각 점검)
2. ✅ 기준 문서 개정: `01`(컷오프), `02`(시점·타깃), `03`(데이터 구조), `05`(B 기준 표시)
3. ✅ 중립 구간 16틱 (과거 1년 일간 변동 중앙값 32틱의 절반)
4. ✅ 코드 전환 (§8) + 11/06 데이터로 전 과정 시험 통과 (`05_실행구조.md`)
5. 첫 정식 실행 (08:45 전 리포트 다운로드) → V0 시험 운영
6. 멘토에게 v0.3 흐름 공유
