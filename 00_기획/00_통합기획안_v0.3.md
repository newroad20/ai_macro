# 통합 기획안 v0.3 — 데일리 리서치 + 전일 종가 기반 다음 거래일 예측 (멘토 안)

> 상태: 초안 (2026-11-09). 멘토의 원래 기획을 주 트랙으로 채택하고, v0.2의 누수 방지·평가 구조를 그대로 가져옴.
> v0.2의 B 트랙(10:00 → 당일 마감)은 **중단·보관**. 코드는 남겨 두고 운영하지 않는다.
> `[결정필요]`는 사용자 확정 전까지 잠정값.

---

## 0. 멘토 기획 (원문 요지)

1. FnGuide에서 매일 쓸 데일리 리서치를 하나 정한다.
2. 함께 줄 정보를 정한다. 예: 전일 미국 지수·채권·환율, 국내 지수·채권·환율 종가.
3. AI가 데일리와 전일 정보를 바탕으로 **다음날**을 근거와 함께 예측한다.
4. 이를 **LLM으로 평가**한다.

## 1. 핵심 질문

> 데일리 리서치 1개와 전일 종가만으로, AI가 다음 거래일 국내 채권 방향을 **단순 기준선보다 낫게** 맞히는가? 그 근거는 타당한가?

거래 없이 예측과 평가만 기록한다.

## 2. 하루 흐름 (거래일 D)

```text
D-1 15:45   국내 장 마감 (국채선물)
D   새벽    미국 장 마감
D   08:30   [기록] D-1 종가 입력 + 데일리 리포트 확보
            [예측] 격리된 AI 세션이 D 종가 방향·근거 예측 → 저장 후 수정 불가
D   08:45   국채선물 개장 (= 예측 컷오프)
D   15:45   [정답] D 종가 기록 (별도 폴더)
D   마감 후  [평가] LLM 근거 채점 + 수치 기록
```

- **컷오프 08:45.** 이후 실행분은 `late`로 분리하고 정식 성과에서 제외한다.
- 개장 전에 실행하므로 간밤 미국 장 결과가 반영된다(v0.2 A 트랙의 약점 해소).

## 3. 입력

### 데일리 리서치 (확정, 2026-11-09)
- FnGuide의 **DAOL Daily Bond Morning Brief + Eugene's FICC Update** (기존 선정 유지, 08:45 전 발간).
- 입수 시각 = PDF 워터마크의 다운로드 시각. **08:45 전에 내려받은 D일자 발간본만** 그날 입력으로 쓴다. 못 받은 날은 `late`.
- 11/05 샘플은 09:57·10:08에 내려받았으므로, 첫 5거래일의 게시·입수 시각을 기록해 점검한다.

### 전일 종가 (스냅샷 정본)

| 구분 | 항목 | 입력 방식 |
|---|---|---|
| 국내 D-1 | 3Y·10Y 국채선물, KOSPI200, 원/달러 | 직전 정답 파일에서 자동 |
| 미국 D-1 | S&P500·Nasdaq 등락률, 미국채 10Y 1일 변화(bp) | 아침에 수동 3개 |
| 참고 | 국고채 금리, 미국채 2Y, DXY, 유가 등 | 리포트 수치 사용 |

- 미국 값은 D-1 미국 장(한국 시각 D 새벽 마감) 기준.
- 국채선물은 **같은 월물끼리** 비교한다. 만기 교체 주간에는 어느 월물을 쓸지 미리 정해 둔다 `[결정필요]`.
- 상세: `02_예측시점_및_타깃.md`, `03_데이터구조.md` (트랙명 **A**).

## 4. 예측 대상과 출력

- **주 타깃 (단일):** 10년 국채선물, **D 정규장 종가 − D-1 정규장 종가 (틱, 1틱 = 0.01pt)**. 성과 결론은 이 하나로만 낸다.
- 보조(기술 통계만, 결론에 쓰지 않음): 3년 국채선물, KOSPI200, 원/달러
- 출력 JSON: 방향(up/neutral/down), 확률, 예상 틱, 확신도(상/중/하), 근거(상승 요인·하락 요인·이미 반영된 요인·무효화 조건).
- **AI는 중립을 예측할 수 있다.** 중립 = 예상 변동 절댓값 16틱 이하.
- **무효화 조건은 기록되는 값(4개 종목 종가, 국채선물 시가)만으로 판정 가능해야 한다.** 장중 고저·장중 경로·외부 지표 금지 (예측 지침 A_v1.1).

### 기준 가격·월물
- **기준 가격 = KRX 정규장(15:45) 공식 종가.** 야간거래 종가·정산가는 기준으로 쓰지 않는다. 야간 종가는 확인되면 **입력 정보**로만 넣는다(선택). 야간거래 시행 여부는 확인 필요 `[확인필요]`.
- **월물 교체 규칙 (사전 고정):** 최근월물 만기일(3·6·9·12월 셋째 화요일)이 속한 주의 **직전 주 월요일**부터 차근월물을 쓴다. 12월물 만기 2026-12-15(추정, KRX 확인 필요) → **2026-12-07부터 2703물**. 교체일에는 새 월물의 전일 종가를 직접 입력하고, 스냅샷·정답에 월물을 기록한다. 점검 기간 안에 걸리므로 교체 전후를 따로 표시해 본다.

### 중립 구간 (사전 고정)
- **16틱.** KRX 10년 국채선물 지수 244일(2025-11-07~2026-11-09) 일간 변동을 틱으로 환산: |변동| 평균 38틱, 중앙값 32틱 → 사전 규칙(중앙값의 절반) 16틱. 중립 비율 약 21%.
- 운영 시작 후 결과를 보며 바꾸지 않는다.

## 5. 평가

### 수치 평가 (주 지표, 사전 고정)
- ① **신호당 평균 획득 틱:** AI가 상승·하락을 낸 날 전체(실제가 중립인 날 포함)의 부호 × 실제 변동. 작은 움직임에서 맞힌 것은 작게 반영된다.
- ② **방향 적중률:** AI가 상승·하락을 낸 날 중 **실제 변동이 중립 구간 밖인 날만** 판정한다. 실제 중립일은 적중률에서 제외(운으로 갈리는 날을 빼기 위함).
- AI가 중립을 낸 날은 신호 없음(획득 0).
- 보조: 확신도별 적중, 틱 오차, **시가 갭과 시가→종가 방향**(시가를 기록한 날, 간밤 재료가 개장에 얼마나 반영됐는지 보기 위함).

### 기준선 (같은 규칙으로 채점)
1. 전일 국내 움직임 지속 / 2. 반전 / 3. 항상 중립
4. 데일리 리포트의 방향 전망 추종 (장 마감 전 수동 태깅)
5. **간밤 미국채 10Y 금리 방향 추종** (±2bp 이상일 때). 개장 갭 때문에 강한 규칙일 가능성이 큼. AI가 이 규칙 **이상**의 무엇을 하는지가 핵심 질문
6. **항상 상승 / 항상 하락** (기간 중 더 많이 나온 방향을 표시. 가장 기본 기준선)

### LLM 근거 평가 — 2단계 (결과 편향 차단)
1. **1단계 (정답 없음):** 예측 직후 별도 세션이 예측·입력값·리포트 원문만 보고 채점해 **먼저 저장**한다. 근거 수치 대조(표의 행·열까지), 추론 타당성(요인 크기 비교, 확률·틱·확신도 정합), 무효화 조건이 판정 가능한 형식인지, 애널리스트 의존도. 정답 파일을 작업 폴더에 넣지 않으므로 구조적으로 결과를 볼 수 없다.
2. **2단계 (정답 공개):** 1단계 결과를 고정한 채, 정답·수치 평가를 보여주고 무효화 조건 발동, "이미 반영" 판단, 추론-결과 분류(옳은 이유로 맞음 / 타당했으나 틀림 등), 일반화 가능한 교훈을 판정한다. 1단계 점수는 다시 매기지 않는다.
- 채점 모델은 예측 모델과 다른(상위) 모델.
- **채점 신뢰도 점검:** 주 1회 정도 같은 예측을 다시 채점(`--variant`)해 점수 차이를 보고, 몇 건은 사람이 같은 기준으로 채점해 LLM 점수와 비교한다(`--agreement`). 차이가 크면 LLM 점수를 결론에 쓰지 않는다.

## 6. 누수 방지·정보 시점

- [ ] 리포트 생성 시각(PDF)과 입수 시각(FnGuide 워터마크) 매일 자동 기록. 둘 중 하나라도 08:45 이후면 `late`
- [ ] 미국 값은 세션 날짜와 출처·확인 시각(`--us-source`) 기록
- [ ] 스냅샷 기록·**예측 실행** 모두 08:45 전. 아니면 `late` (정식 성과 제외)
- [ ] 예측 저장 후 수정 불가, 정답은 별도 폴더, 예측 세션 접근 불가
- [ ] 정답 기록 시각 > 예측 실행 시각 (평가 시 자동 검사)
- [ ] 매일 새 격리 세션 (전역 설정·메모리 미로드)
- [ ] **점검 기간 중 모델·프롬프트 고정** (claude-sonnet-5-5, A_v1.1 / 채점 claude-opus-5, A_blind·A_outcome v2.0). 다르면 정식 실행 거부
- [ ] 과거 날짜 소급 검증 시 모델 지식 컷오프 이후 날짜만 사용

### 결측·휴장
- 한국 휴장일은 건너뛰고 D-1 = 직전 국내 거래일. 미국 휴장 다음 날은 직전 미국 세션을 명시.
- **두 리포트 중 하나라도 08:45 전에 확보하지 못하면 그날은 정식 표본에서 제외**(시험 실행만). 한 리포트만으로 돌리면 입력 조건이 달라지기 때문.

## 7. 실험 버전

- **V0 (점검 운영, ~20거래일, 2026-11-10~):** 흐름이 매일 문제없이 도는지 확인. **성능 결론 없음.** 20일 중 14일(70%)을 맞혀도 동전 던지기로 그만큼 나올 확률이 약 6%이고, 날마다 시장 상황이 이어지기도 해 실제로는 더 불확실하다.
- **V1:** 프롬프트 고정 운영. 성능 판정에는 약 150거래일 필요. 일별 종가와 과거 리포트를 구할 수 있으면 소급 검증으로 단축 가능.
- **V2:** 입력 요인을 하나씩 추가하며 V1과 비교.
- **리포트 기여도 (V0 이후 검토):** 두 리포트를 함께 넣으면 어느 쪽이 도움이 됐는지 알 수 없다. 예측 세션이 독립적이므로 같은 날 (둘 다 / 다올만 / 유진만) 세 가지로 예측해 비교할 수 있다. 비용이 세 배라 점검 기간 뒤 판단한다.

## 8. 기존 구현 재사용

| 구성 | 처리 |
|---|---|
| 격리 실행 (`run_prediction.py`) | 그대로. 입력 파일 구성만 변경 |
| 기록 (`record.py`) | 입력 항목을 전일 종가 목록으로 변경 |
| 예측 스키마·지침 | 타깃을 "다음 거래일 종가"로 수정 → 지침 v2.0 |
| 수치 평가 (`evaluate.py`) | 정답 기준을 전일 종가 대비로, 기준선 5번 추가 |
| 근거 채점 (`judge_rationale.py`) | 그대로. 지침 문구만 수정 |
| B 트랙 데이터·결과 | 보관 (운영 중단) |
