## A 트랙 운영 (현재)

```text
# 거래일 D, 08:45 전 (다올·유진 D일자 PDF를 01_리서치_원본/<D>/ 에 넣은 뒤)
python 06_코드/record.py snapshot <D> --spx <S&P %> --ndx <나스닥 %> --ust10y <미국채10Y bp> --contract 2612        --us-source "<출처 확인시각>" [--night-f10 … --night-f3 …]
python 06_코드/run_prediction.py <D>
python 06_코드/judge_rationale.py <D> --stage blind      # 1단계 채점 (정답 없이, 예측 직후 저장)

# D 장 마감 후
python 06_코드/record.py answer <D> --f3 … --f10 … --k200 … --fx … --contract 2612 [--o10 … --o3 …]
python 06_코드/evaluate.py <D>
python 06_코드/judge_rationale.py <D> --stage outcome    # 2단계 판정 (정답 공개)
python 06_코드/evaluate.py --summary
python 06_코드/evaluate.py --sources                # 근거 출처 분포 (daol/eugene/미국, 예측 파일만 사용)

# 주 1회 채점 신뢰도 점검
python 06_코드/judge_rationale.py <D> --stage blind --variant r2
python 06_코드/judge_rationale.py --agreement            # 사람 점수: 05_평가결과/A/human/<D>.json
```

- **사람이 넣는 값: 아침 3개 + 마감 4개.** 국내 전일 종가는 직전 정답 파일에서, 10년·3년 선물 전일 변동은 직전 두 정답 파일에서 자동으로 채운다. 첫날은 `--prev-f3 --prev-f10 --prev-k200 --prev-fx`와 `--prev-ticks10 --prev-ticks3`으로 직접 준다.
- **late 판정 (컷오프 08:45):** 스냅샷 기록, 리포트 생성·입수(워터마크) 시각, **예측 실행 시각** 중 하나라도 08:45 이후면 late.
- **중립 구간 16틱:** 과거 1년(244일) 10년 선물 일간 변동 중앙값 32틱의 절반. 중립 비율 약 21%.
- **기준선:** momentum(전일 변동 지속) / reversal / neutral / **us_rates**(간밤 미국채 10Y가 ±2bp 이상이면 그 반대 방향 = 금리 하락 시 up) / report_daol·eugene(태깅 시).
- **채점 2단계 (외부 검토 반영):** 1단계는 정답 파일을 작업 폴더에 넣지 않고 예측·스냅샷·PDF만 보고 근거 수치·추론·무효화 조건 형식을 채점해 저장한다. 2단계는 1단계 결과를 고정한 채 정답·수치평가를 보고 무효화 발동·이미 반영·추론-결과 분류·교훈만 판정한다(PDF 불필요라 저렴). 채점 세션은 구조화 출력이 없을 때만 1회 재시도한다(예측은 재시도 없음).
- **적중률 규칙:** 실제 변동이 중립 구간 안인 날은 적중 판정 없음(hit=null). 신호당 획득 틱에는 포함. 요약에 always_up/always_down 기준선과 시가→종가 부호 일치(시가 기록 시)를 함께 낸다.
- **점검 기간 고정:** `v0_freeze`와 모델·프롬프트가 다르면 정식 실행 거부(`--allow-unfrozen`으로만 허용).
- **월물:** 2026-12-07 이후 스냅샷에서 2703물이 아니면 경고. 교체일엔 새 월물 전일 종가를 직접 입력.
- **프롬프트 (현재):** `predictor_A_v1.1.md`(v1.0 + 무효화 조건을 기록 값으로 판정 가능하게 제한, 야간 종가 안내), `judge_A_blind_v2.0.md`, `judge_A_outcome_v2.0.md`.
- **프롬프트 (이전):** `predictor_A_v1.0.md`(B v1.0 기반 + 11/05 채점 교훈 반영: 스냅샷 값은 실제값, 요인 크기 비교 없이 neutral 금지, 행·열 재확인, 무효화 조건은 "대상+임계값+방향"), `judge_A_v1.0.md`.
- **시험:** 모든 명령에 `--dry-run`. 시험 파일은 `06_코드/dryrun/A/`, `99_로그/dryrun/A/`, `05_평가결과/A/dryrun/`.

## 하루 운영 (가장 간단한 방식)

시트나 폼 없이, **Claude Code에게 숫자를 말로 알려주면** 아래 명령을 실행한다 (직접 실행도 가능).

```text
10:00  "스냅샷: 3년선물 103.62, 10년선물 108.71, 코스피200 395.12, 환율 1339.8, S&P +0.41, 나스닥 +0.62"
       → python 06_코드/record.py snapshot <날짜> --f3 … --f10 … --k200 … --fx … --spx … --ndx …
       → python 06_코드/run_prediction.py <날짜>

15:45~ "마감: 3년 103.90, 10년 108.95, 코스피200 396.40, 환율 1337.5"
       → python 06_코드/record.py answer <날짜> --f3 … --f10 … --k200 … --fx …
```

- **입력은 스냅샷 6개, 정답 4개.** 리포트 PDF는 `01_리서치_원본/<날짜>/`에 넣어 두기만 하면 된다.
- 자동으로 채움: 기준 시각(설정의 T), 기록 시각(지금), 리포트 생성·입수 시각(PDF), 전일 종가(직전 정답 파일), 미국 세션 날짜(직전 평일).
- 첫날은 직전 정답이 없으므로 `--prev-f3 --prev-f10 --prev-k200 --prev-fx`로 전일 종가를 준다. 미국 휴장일 다음 날은 `--us-date`로 지정한다.
- 막는 것: 거래일 당일이 아닌 정식 기록, 덮어쓰기, 전일 대비 이상치(선물 1~1.5%, KOSPI200 6%, 환율 2.5%, 미국 지수 8% 초과), 예측 전 정답 기록, 15:45 이전 정답 기록, 입력 누락. 연습은 `--dry-run`, 검사 무시는 `--force`.
- 미국 지수는 **등락률만** 받는다 (종가 수치는 스키마상 선택 항목).
- 시험: 임시 폴더로 10개 시나리오(정상·이상치·덮어쓰기·날짜·예측 전 정답·장 마감 전·누락 등) 통과.


## 실행기가 막는 것

- 같은 날짜의 예측 파일이 이미 있으면 거부(덮어쓰기 금지, 자동 재시도 없음). 검증 실패 시 저장하지 않고 로그에만 남긴다.
- `neutral_band_ticks`가 null이면 정식 실행 거부 → 중립 구간을 **사전에 고정**하게 강제.
- 정답 파일이 이미 있으면 정식 실행 거부.
- late(스냅샷 지연, 또는 리포트 생성·입수 시각이 T 이후)이면 `--allow-late` 없이는 거부, 허용 시 `04_예측결과/B/late/`로 분리 저장.
- 확률 합계, direction=확률 최대, duration_view 일치, 틱 부호 일치, 중립일 때 틱 범위를 검사한다.

## 발견된 문제

1. **근거 수치 오독 1건.** 모델이 "국고 10년 3.950%(−4.0bp)"라고 적었으나 다올 원본은 −5.0bp이다(−4.0은 바로 아래 20년물). 텍스트 일치 검사로는 −4.0이 PDF 어딘가에 존재해 걸러지지 않는다.
   - 대응: 평가 단계의 **LLM 근거 평가에 "근거 수치 충실도"** 항목을 넣고, 판정 세션이 PDF를 직접 열어 인용 수치를 대조하게 한다. 예측 점수와 별도로 오독률을 집계한다.
2. 프롬프트 v1.0의 `invalidation_conditions` 문장 일부가 어색하다(예: 「±3틱을 넘어 마감 (상승 시 롱, 하락 시 숏이 맞았음)」). 의미는 통하나, 평가에 쓰려면 "관측 가능한 조건 + 임계값 + 방향" 형식을 요구하도록 v1.1에서 다듬을지 정해야 한다. 정식 운영 전에만 바꾼다.


- **수치 평가** `evaluate.py`: 10년 선물 비중립 신호의 적중·획득 틱을 AI와 기준선(momentum / reversal / neutral / report_daol·eugene)에 동일 적용. 리포트 기준선은 `02_시장데이터/리포트방향/B/<날짜>.json`(마감 전 태깅, 전망 없으면 `none`)이 있을 때만. 예측 실행 시각 ≥ 정답 기록 시각이면 거부.
- **근거 채점** `judge_rationale.py` + `prompts/judge_v1.0.md` + `schemas/judgment.schema.json`: 예측과 같은 격리 방식의 별도 세션이 정답·수치평가·PDF 원본을 보고 ① 근거 수치 충실도(행 단위 대조) ② 이미 반영 판단 ③ 무효화 조건 관측 가능성·발동 ④ 추론-결과 분류(결과론 금지) ⑤ 애널리스트 의존도 ⑥ 일반화 가능한 교훈을 채점.
