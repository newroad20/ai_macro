# PDF 직접 입력 검증 (단계 5, 2026-11-05 샘플 1일치)

> 범위: 폴더에 있는 다올·유진 PDF 각 1건. 원래 목표(각 3일치)에는 미달이므로 결론은 잠정이다.

## 결론

**PDF를 텍스트로 변환하지 않고 원본 그대로 Claude에 읽히는 방식을 채택한다.** 별도 추출 코드는 만들지 않는다.

- Read로 PDF를 읽으면 텍스트 레이어와 페이지 이미지가 함께 전달된다. 다올은 텍스트 레이어만으로는 표의 라벨과 숫자가 분리되지만 이미지로 표 구조가 복원된다.
- 이미지로 읽은 37개 수치(다올 20, 유진 17)를 PDF 텍스트 레이어와 대조한 결과 **누락·오독 0건**.
- 환경 주의: `pages` 인자로 페이지를 지정하면 렌더링 도구(poppler) 부재로 실패한다. 지정 없이 읽으면 정상이다(둘 다 10쪽 이하).

## 발견 사항

### 1. PDF 하단 워터마크에 다운로드 시각이 박혀 있음

```text
DB Copyright © FnGuide Inc. (FG::<계정>::<번호>::<IP 일부>::2026-11-05 09:57)   ← 다올
DB Copyright © FnGuide Inc. (FG::<계정>::<번호>::<IP 일부>::2026-11-05 10:08)   ← 유진
```

- 이 시각이 곧 `obtained_at`이다. 수동 기록 대신 PDF에서 읽을 수 있다(두 시각은 파일 저장 시각과도 일치).
- 샘플 일에는 유진이 10:08에 입수되어 **T=10:00 기준으로는 실시간 운영 시 사용 불가**였다. 이날만의 우연일 수 있어, 5거래일 입수 로그로 판단한다.
- 워터마크에는 계정·번호·IP 일부가 있다. 외부 공유 시 노출 주의. 유진 리포트는 무단 복제·배포 금지 문구가 있으므로 멘토 등에게 PDF 원본을 넘기기 전에 이용 약관을 확인할 것.

### 2. 두 리포트의 같은 항목이 서로 다름

| 항목 | 다올 | 유진 |
|---|---|---|
| 3Y 선물 1D / 10Y 선물 1D (틱) | 9.0 / 39.0 | 9.0 / 39.0 (일치) |
| 3Y 선물 1W (틱) | 22.0 | **35.0** |
| 10Y 선물 1W (틱) | 105.0 | **145.0** |
| 국고 3Y 수익률 / 1D | 3.707 / −3.0bp | 3.714 / −2.2bp |
| 국고 10Y 수익률 / 1D | 3.950 / −5.0bp | 3.968 / −3.3bp |
| UST 10Y, 원/달러 | 4.889, 1,341.5 | 4.889, 1,341.50 (일치) |

- 선물 종가·1일 변화, 미국채, 환율은 일치한다. **1주 변화와 국고채 수익률은 불일치**한다(기준일 또는 산출 방식 차이로 추정, 미확인).
- **규칙:** 프롬프트에서 수치 충돌 시 어느 리포트 값인지 명시하게 한다. 가격·전일 종가는 스냅샷을 정본으로 하고, 리포트 수치는 맥락 참고용으로 쓴다.

### 3. 날짜 기준

두 리포트 모두 11/5자 발행이며 수치는 **11/4 국내 마감 + 미국 11/4(현지) 세션**이다. 스냅샷의 `us_close.as_of_date`는 "한국 당일 개장 전에 끝난 직전 미국 세션"으로 정의하고, 첫 운영일에 실제 S&P 종가 날짜와 대조해 확인한다 `[확인필요]`.

### 4. 입력에 없는 것 / 있는 것

- **없음:** S&P 500·Nasdaq 지수(기존 판단 확인). 별도 입력 유지.
- **있음 (환율·원자재):** 유진에 달러지수, 유로·엔·위안, WTI, 금, 비트코인이 있다.
- **V2 후보:** 다올에 주체별 국채선물 순매수(외국인 당일 +14,033계약, 5일 +23,685계약 등)가 있다. 3년·10년 구분이 PDF에 표시돼 있지 않아 어느 종목인지 불명확하다 `[확인필요]`. 유진의 외국인 선물 수급은 차트뿐이라 수치로 읽을 수 없다.
- **유진 해석 문장:** "국내 채권시장 동향", "전망 및 향후 주요 이벤트" 등 서술이 충실해 근거 생성에 적합하다. 다만 애널리스트 전망이 섞여 있어 §5의 "리포트 방향 추종 기준선"이 필요하다.
